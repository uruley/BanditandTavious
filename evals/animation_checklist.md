# Animation Checklist

## Goal

Use this checklist when a Neo loop touches animation, camera-body coupling, or traversal visuals.

## Checklist

- [ ] The expected `AnimationPlayer` or animation path still exists.
- [ ] Idle, movement, and transition states still resolve without missing clip errors.
- [ ] Body orientation still matches movement/camera assumptions.
- [ ] New animation logic does not break the current multiplayer or sandbox branch contract.
- [ ] Any durable animation workflow lesson is written back to memory/wiki, not buried in ad-hoc notes.
